# 정식 나이스 개발 루프 (학교 PC용)

학교 PC에서 Claude Code와 정식 나이스를 같이 띄워 두고, 사이드패널 **[자동 입력]** 이 목표까지 될 때까지
**실행 → 판정 → (실패 시) 로그·진단 파일 확인 → 코드 수정 → 다시 실행**을 반복하는 도구입니다.

- `run.mjs`: 한 바퀴 실행. 확장 새로 불러오기 → 사이드패널 열기 → 개발용 **예시 데이터**(행발 또는 과세특, 학생 10명) 받기
  → **[자동 입력]**(화면 열기 → 조회 → 반/번호로 맞춰 넣기) → 판정 → 예시 문구 버리기(다시 조회).
  마지막 줄에 JSON 결과를 내고, 목표 달성이면 종료 코드 0, 아니면 1.
- `cdp.mjs`: Chrome 디버깅 포트 연결 도구.
- `../mock-neis/`: 모의 나이스 (`python3 tools/mock-neis/server.py --port 8770` → <http://127.0.0.1:8770/neis/>). 정식 나이스에서 본 동작을 여기에 옮겨 두고 먼저 시험합니다. 고칠 때는 이 폴더를 고치고 같이 커밋합니다.

## 목표 (이 조건을 모두 만족하면 끝)

1. [자동 입력]이 멈추지 않고 끝남 (팝업이 "…건 입력 완료")
2. 예시 10명이 모두 자기 반/번호 행에 들어감 (`검증.right` 10), 엉뚱한 행 0 (`검증.wrong` 0)
3. 끝난 뒤 예시 문구를 저장 없이 버림

`run.mjs` 결과의 `"목표달성": true`가 이 조건을 모두 만족했다는 뜻입니다.
예시 데이터는 묶음 하나라서 [자동 입력]이 [저장]을 누르지 않습니다.

## 개인정보 규칙 (반드시 지킬 것)

정식 나이스 화면에는 학생 이름과 학생부 문구가 있습니다. 화면 내용이 AI(Claude)로 전송되지 않도록 다음을 지킵니다.

- 화면 정보는 **`run.mjs` 출력과 로그·진단 파일(`neis-자동입력-*.json`, `neis-진단-*.json`)로만** 봅니다. 둘 다 학생 이름·문구가 없거나 ▒▒▒로 가려져 있습니다.
- 나이스 탭의 DOM 원문, 텍스트, 스크린샷을 직접 읽지 않습니다 (Playwright/Chrome 도구의 snapshot·screenshot·get_page_text 금지).
- 진단 파일을 고칠 때 학생 이름이 보이면 작업을 멈추고 사람에게 알립니다 (가리기 규칙을 먼저 고침).
- 진단 파일과 결과를 커밋하거나 외부에 올리지 않습니다.

## 안전 규칙

- 나이스의 **저장·삭제·일괄적용 버튼은 사람도 스크립트도 누르지 않습니다.** 개발 루프의 예시 데이터는 묶음 하나라 [자동 입력]이 저장하지 않습니다.
  (조회조건이 다른 **묶음** 데이터는 [자동 입력]이 묶음마다 [저장]까지 하므로, 정식 나이스에서는 실제 넣을 문장으로만 씁니다.
  개발용 [과세특 묶음 예시]는 정식 나이스에서 시험 모드(저장 안 함)로 돕니다.)
- 나이스 페이지를 새로고침하지 않습니다 (열린 화면과 세션이 사라짐).
- 저장 여부를 묻는 창에는 `아니오`만 누릅니다. 처리 방법을 모르는 창이 뜨면 멈추고 사람을 부릅니다.
- 2차인증은 사람이 직접 합니다. 스크립트는 기다리기만 합니다 (최대 10분).

## VPN 때문에 Claude Code 와 나이스를 같이 못 쓸 때 (Windows)

학교 밖에서 VPN 을 켜면 인터넷이 끊겨 Claude Code 를 쓸 수 없는 경우(학교 안에서는 VPN 이 필요 없음), **VPN 을 켠 채 사이드패널에서 직접 돌리고, VPN 을 끈 뒤 파일만 전달**합니다.
Node.js·디버깅 Chrome 은 필요 없습니다. 평소 쓰는 Chrome 에서 하면 됩니다.

1. 받은 압축 파일을 `C:\neisshot` 같은 곳에 풉니다 (`manifest.json` 이 보이는 폴더).
2. Chrome 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 1번 폴더 선택.
   웹스토어판 나이스입력도우미가 있으면 잠시 꺼 둡니다 (둘 다 켜져 있으면 어느 쪽 사이드패널인지 헷갈림).
3. 같은 Chrome 에서 나이스에 로그인합니다. 학교 안에서는 VPN 이 필요 없고, 학교 밖에서 접속할 때만 VPN 을 먼저 연결합니다.
4. issamGPT 에서 보내거나, 사이드패널 개발용 칸의 **예시 데이터**로 데이터를 받은 뒤 **[과세특/행특 자동 입력]** 을 누릅니다.
   2차인증 창이 뜨면 번호를 넣습니다.

### 자동 입력 로그 (개발 설치에서만)

- [자동 입력]을 할 때마다(성공·멈춤 모두) 다운로드 폴더에 로그 파일이 저장됩니다. 파일 이름만 봐도 결과를 알 수 있습니다:
  **`neis-자동입력-성공-날짜-시각.json`** / **`neis-자동입력-멈춤-날짜-시각.json`** (파일 이름은 팝업이나 상태줄에 나옵니다).
- 파일 안 `결과.성공`(true/false), `결과.멈춘단계`, `결과.오류`, `결과.마지막입력`(넣은 수·건너뛴 수·표에 없음·이름 다름), `결과.묶음별` 로 확인합니다.
- 파일에 담기는 것: 어디서 멈췄는지(묶음·단계)와 오류, 나이스 창 문구, 묶음별 결과(숫자만), 단계마다의 가린 화면 구조
  (시작 → 화면 열림 → 묶음마다 조회 후 / 입력 후 / 저장 후 → 멈춘 곳, 최근 8개), 표 상태(행·칸 위치, 스크롤 값),
  입력칸을 못 연 칸 기록, 저장 때 거친 창(확인/완료/알림).
- 학생 이름·문구·상단 사용자 정보·알림 내용은 ▒▒▒ 로 가리고, 받은 데이터의 이름과 화면의 성명으로 한 번 더 대조해 가립니다.
- 파일을 메모장으로 열어 (VPN 을 썼다면 끊은 뒤) `Ctrl+F` 로 학생 이름 몇 개가 **안 나오는지** 확인한 뒤 전달합니다
  (`가리기점검.추가로가린곳` 이 0 이 아니면 그것도 알려 주세요).
- 멈춘 묶음은 저장되지 않았을 수 있습니다. 나이스 화면을 확인하고, 시험 문구라면 저장하지 말고 [조회]를 다시 눌러 버립니다.

### 그 밖의 개발용 도구

- **지금 화면 진단 저장**: 지금 나이스 화면 구조를 가린 파일(`neis-진단-*.json`) 하나로 저장. 사이드패널에서는 숨겨 두었고, `run.mjs` 가 검증 실패 때 씁니다.
- **수동 화면 수집**: 직접 메뉴를 누르며 원하는 순간마다 [지금 화면 담기] → [파일로 저장]. 아직 자동으로 못 여는 화면(평어·창체 등)의 구조를 받을 때 씁니다.

### 예시 데이터로 직접 넣어 보기

issamGPT 없이 같은 형식(`docs/issamgpt-message-format.md`)의 데이터를 받은 것처럼 넣어 봅니다.

1. 나이스에서 화면을 열고 조회합니다 (과세특이면 과세특 화면).
2. 사이드패널 개발용 칸 맨 아래 **예시 데이터** → **[지금 나이스 표의 반/번호·조회조건으로 채우기]** → **[이 데이터로 받기]**.
   (JSON 을 고쳐서 받아도 됩니다. 학생 순서를 바꾸거나 몇 명 지워 보세요.)
3. 미리보기에 반/번호가 보이고, 조회조건이 있으면 **[이 조건으로 나이스 조회]** 가 생깁니다.
4. **[과세특/행특 자동 입력]** → `[예시 반/번호]` 가 그 학생 행에 들어갔는지 봅니다.
5. 정식 나이스에서는 **저장하지 말고** [조회]를 다시 눌러 버립니다.

### 과세특 묶음 예시 (학년·과목·강의실이 다른 묶음 → 묶음마다 조회·입력)

> 지금은 사이드패널에서 숨겨 두었습니다. 다시 쓰려면 `sidepanel.html` 의 `btnDevSampleGroups` 버튼에서 `hidden` 을 지웁니다.

1. 과세특 화면을 엽니다.
2. 사이드패널 개발용 칸 **예시 데이터 → [과세특 묶음 예시]**: 화면의 학년·과목·강의실 목록에서 과목·강의실이 서로 다른 조합 3개를 골라
   조합마다 조회하고, 실제 명단 앞 10명(반/번호·성명)으로 묶음을 만들어 받습니다. (고르는 동안 조회조건이 바뀝니다. 입력·저장은 안 함)
3. **[과세특 자동 입력]** → 확인 창에서 진행.
   - **정식 나이스: 시험 모드** — 저장하지 않습니다. 묶음마다 조회 → 입력 → `[예시 반/번호]` 가 맞는 행에 들어갔는지 세기 → [조회]를 다시 눌러 버림
     (저장 여부 창에는 **아니오**만 누름). 끝 팝업에 묶음별 "맞는 행 / 엉뚱한 행" 이 나옵니다.
   - 모의 나이스: 묶음마다 [저장]까지 합니다.
4. 시험 모드는 새 데이터를 받으면(issamGPT 또는 다른 예시) 자동으로 꺼집니다.

## 준비 (한 번만)

1. **Node.js 22 이상**: `node -v`로 확인합니다.
2. **디버깅 포트를 연 Chrome을 따로 띄웁니다.** 평소 쓰는 Chrome 프로필로는 디버깅 포트가 열리지 않으므로, 별도 프로필 폴더를 씁니다.
   - Windows (PowerShell):
     ```powershell
     & "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="$env:USERPROFILE\neis-dev-chrome"
     ```
   - macOS:
     ```bash
     "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --remote-debugging-port=9222 --user-data-dir="$HOME/neis-dev-chrome"
     ```
3. 그 Chrome 창에서 `chrome://extensions` → 개발자 모드 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 이 저장소 폴더(`manifest.json`이 있는 폴더)를 고릅니다.
   웹스토어판 나이스입력도우미가 설치돼 있으면 이 창에서는 꺼 둡니다.
4. 같은 창에서 **나이스에 로그인**합니다. 인증서 로그인도 이 창에서 하면 됩니다.
5. 연결 확인: `node tools/neis-dev-loop/run.mjs --discard` → `"목표달성": true`(예시 문구 없음)가 나오면 준비 완료입니다.

포트를 9222가 아닌 다른 번호로 띄웠다면 `CDP_PORT=번호`를 붙입니다. 다운로드 폴더가 기본(`~/Downloads`)이 아니면 `NEIS_DIAG_DIR=경로`를 붙입니다.

## 한 바퀴 실행

```bash
node tools/neis-dev-loop/run.mjs            # 행특 예시 (3학년 1반 1~10번)
node tools/neis-dev-loop/run.mjs --seteuk   # 과세특 예시 (1학년 공통수학2 강의실 5, 5/1~5/10)
```

- 예시 데이터(사이드패널에서는 숨긴 [과세특 예시]/[행발 예시] 버튼)의 학년·반·강의실은 모의 나이스 명단 기준입니다. 정식 나이스에서는 개발용 칸의 JSON 을 그 학교에 맞게 고치거나,
  화면을 연 뒤 [지금 나이스 표의 반/번호·조회조건으로 채우기]로 받은 다음 사이드패널에서 직접 [자동 입력]을 누릅니다.
- 진행 상황은 표준 오류로, 최종 결과(JSON)는 표준 출력으로 나옵니다.
- `👤 2차인증 창이 떴습니다` 가 나오면 사람이 인증합니다. 인증하면 이어서 진행됩니다.
- 옵션: `--no-reload`(코드 안 바꿨을 때), `--keep`(예시 문구를 사람이 눈으로 보도록 남김, 확인 후 `--discard`), `--discard`(버리기만).

결과 예:

```json
{
  "목표달성": false,
  "실행버튼": "행특 자동 입력",
  "완료팝업": "10명 중 9건 입력 완료 / …",
  "검증": { "rows": 28, "right": 9, "wrong": 0 },
  "사유": ["맞는 행 9/10"],
  "진단파일": ["C:\\Users\\...\\Downloads\\neis-자동입력-20261124-101500.json"]
}
```

## 예상 못한 실패도 처리되는 방식

| 상황 | 동작 |
|---|---|
| 코드 수정 중 문법 오류 | 나이스에 손대기 전에 `node --check`·manifest 점검 → "코드 문법 오류 → 파일:줄" |
| [자동 입력]이 멈춤 (화면·조회·입력칸·저장 중 하나) | 팝업에 이유 + `neis-자동입력-*.json` (단계별 화면 구조·표 상태) |
| 끝나지 않음 | 6분 뒤 끝내고 지금 화면 진단 파일 저장 |
| 끝났지만 검증 실패 (밀림·빠짐) | 지금 화면 진단 파일 저장 |
| 처음 보는 나이스 창 | 저장 중 알림 창은 [확인]으로 닫고 계속, 묻는 창(저장이 아닌 것)은 멈춤 → 로그에 창 문구 |
| 진단 파일에 학생 이름이 남음 (가리기 실패) | 화면의 학생 명단과 대조해 발견하면 파일 이름을 `…가리기실패-사람확인`으로 바꿔 격리, Claude 에게 넘기지 않고 "사람 확인 필요" |
| 예시 문구를 못 버림 | "사람 확인 필요" → 사람이 저장하지 말고 다시 조회 |
| Chrome 종료·세션 끊김·확장 불러오기 실패 | "스크립트 오류: …" 로 끝남 (사람이 Chrome·로그인 상태 확인) |

어떤 경우든 같은 사유가 2번 연속 고쳐지지 않거나 8바퀴를 넘기면 Claude Code 가 멈추고 보고합니다.
