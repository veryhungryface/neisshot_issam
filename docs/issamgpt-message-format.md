# issamGPT → 나이스입력도우미 데이터 전달 형식

issamGPT 페이지에서 확장 프로그램으로 학생부 문장을 보낼 때 쓰는 메시지 형식입니다.
받는 코드는 `background.js` 의 `chrome.runtime.onMessageExternal` 입니다.

## 보내는 방법

```js
chrome.runtime.sendMessage(EXTENSION_ID, payload, (res) => {
  if (chrome.runtime.lastError) { /* 확장 프로그램이 없거나 꺼져 있음 → 설치 안내 */ return; }
  // res: { ok: true, count: 27, students: 27, query: true } 또는 { ok: false, error: 'BAD_PAYLOAD', detail?: '...' }
  //   students: 학생별 반·번호로 받은 인원 (예전 rows 형식이면 null), query: 조회조건을 받았는지
});
```

보낼 수 있는 페이지는 `manifest.json` 의 `externally_connectable.matches` 에 있는 주소뿐입니다
(issamgpt.com 및 하위 도메인, localhost 등).

## 형식 (권장: 학생별 반·번호 포함)

```js
{
  type: 'NEISSHOT_DATA',           // 필수, 고정값
  category: 'seteuk',              // 화면 종류 (아래 표)
  subject: '공통수학2',             // 선택: 미리보기 제목에 표시

  // 선택: 나이스 조회조건. 있으면 사이드패널에 [이 조건으로 나이스 조회] 버튼이 생긴다.
  query: {
    year: '2026',                  // 학년도
    semester: '2',                 // 학기 ('2', '2학기' 모두 가능)
    grade: '1',                    // 학년 (과세특 화면의 '계열/학년/학과')
    ban: '5',                      // 반 (행특·창체 등 담임 화면)
    subject: '공통수학2',           // 과목 (나이스 표기 '공통수학2(4)' 와 앞부분이 같으면 맞춤)
    room: '5',                     // 강의실 (과세특 화면)
  },

  // 학생별 데이터. 순서는 상관없다 (나이스 표의 반/번호를 보고 맞는 행에 넣는다).
  students: [
    { ban: '5', no: 1, name: '홍길동', text: '세특 문장...' },
    { ban: '5', no: 2, name: '김철수', text: '...' },
  ],
}
```

### 초등 학급담임 (교과 세특)

초등도 `category: 'seteuk'` 로 보낸다. 확장 프로그램이 나이스에 '교과담임' 역할이 없고 '학급담임'이 있으면
**학급담임 › 성적 › 학생평가 › 학기말종합의견** 화면으로 들어가 교과(목)별로 조회해 넣는다.

```js
{
  type: 'NEISSHOT_DATA', category: 'seteuk', subject: '국어',
  query: { year: '2026', semester: '2', grade: '6', ban: '1', subject: '국어' },   // room(강의실) 없음, subject 는 교과(목)
  students: [ { ban: '1', no: 1, name: '홍길동', text: '...' }, ... ],
}
```

- 교과가 여러 개면 `groups` 로 교과마다 묶음을 나눈다 (묶음마다 조회 → 입력 → 저장).
- `semester` 는 `'2'`, `'2학기'` 모두 된다 (초등 화면의 학기 칸은 `2` 처럼 숫자만).

### 여러 묶음 (과세특: 학년·과목·강의실이 다른 학생을 한 번에)

조회조건이 다른 학생들을 한 번에 보낼 때는 `query` + `students` 대신 `groups` 를 쓴다.
자동 입력이 묶음마다 **조회 → 입력 → [저장]** 을 하고 다음 묶음으로 넘어간다 (시작 전에 사용자에게 한 번 묻는다).

```js
{
  type: 'NEISSHOT_DATA',
  category: 'seteuk',
  groups: [
    { query: { year: '2026', semester: '2', grade: '1', subject: '공통수학2', room: '5' },
      students: [ { ban: '5', no: 1, name: '홍길동', text: '...' }, { ban: '5', no: 2, name: '김철수', text: '...' } ] },
    { query: { year: '2026', semester: '2', grade: '2', subject: '확률과 통계', room: '2' },
      students: [ { ban: '2', no: 7, name: '이영희', text: '...' } ] },
  ],
}
// res: { ok: true, count: 3, students: 3, groups: 2, ... }
```

- 묶음마다 `query` 가 있어야 한다 (없으면 `BAD_PAYLOAD`). `students` 규칙은 아래와 같다.
- 묶음이 하나뿐이면 `query` + `students` 로 보낸 것과 같고, 저장은 사람이 누른다.
- 저장 중 나이스가 확인·완료가 아닌 창(바이트 초과, 오류 등)을 띄우면 거기서 멈추고 창 내용과 묶음별 결과를 보여 준다.

### students 규칙

| 필드 | 필수 | 설명 |
|---|---|---|
| `no` | 필수 | 번호. 숫자 또는 문자열 (`3`, `'03'`, `'3번'` 모두 3) |
| `ban` | 권장 | 반. 강의실에 여러 반 학생이 섞이는 과세특에서는 꼭 보내야 한다. `'1-5'` 처럼 보내면 마지막 숫자(5)를 반으로 쓴다 |
| `name` | 권장 | 이름. 보내면 나이스 표의 성명과 비교해 다르면 **넣지 않고** 알려 준다 (공백 무시) |
| `text` | 필수 | 넣을 문장. 빈 문장인 학생은 빠진다 |

- `no` 가 없는 학생이 하나라도 있으면 전체를 거절한다 (`BAD_PAYLOAD`).
- 데이터에 없는 학생 행은 건드리지 않는다. 표에서 찾지 못한 학생은 입력 후 목록으로 보여 준다.

## 예전 형식 (계속 받음)

```js
{ type: 'NEISSHOT_DATA', category: 'behavior', subject: '', rows: ['1번 문장', '2번 문장', ...] }
```

`rows` 만 오면 사용자가 커서를 둔 칸부터 표 순서대로 한 행씩 넣는다 (학생 맞춤 없음).
`students` 와 `rows` 가 함께 오면 `students` 를 쓴다.

## category 값

| 값 | 화면 (나이스 메뉴) |
|---|---|
| `seteuk` | 교과담임 › 성적 › 성적처리 › 과목별세부능력및특기사항 |
| `subject` | 학급담임 › 학생평가 › 학기말종합의견 |
| `creative` | 학급담임 › 창의적체험활동 › 자율자치활동(자율활동)관리 |
| `behavior` | 학급담임 › 행동특성및종합의견 › 행동특성및종합의견 |

한글 이름(`과세특`, `행발`, `창체` 등)도 알아듣지만 위 영문 값을 권장한다.

## 사용자 흐름

1. issamGPT 에서 보내기 → 사이드패널 미리보기 제목이 종류에 맞게 바뀌고(과세특/행동특성및종합의견 …) 반/번호와 문장이 보인다.
2. **과세특(`seteuk`)·행특(`behavior`)**: 실행 버튼이 [과세특 자동 입력] / [행특 자동 입력] 으로 바뀐다. 누르면
   나이스 탭을 찾아 → 해당 화면을 메뉴로 열고(2차인증 번호는 사람이 입력) → `query` 로 조회 → 첫 학생 입력칸을 열고
   → 반/번호(번호)에 맞춰 넣는다. 나이스 탭은 사용자가 미리 열고 로그인해 둔다 (시도교육청마다 주소가 달라 새로 열지 않는다).
3. **그 밖의 종류(`subject`, `creative`)**: 예전처럼 사용자가 메뉴 위치 안내를 보고 화면을 연 뒤 첫 칸을 클릭하고 [일괄 입력 실행].
   `query` 가 있으면 [이 조건으로 나이스 조회] 버튼으로 조회조건만 맞출 수 있다.
4. 결과를 확인하고 사람이 직접 [저장] 을 누른다 (확장 프로그램은 저장하지 않는다).

## 개인정보

학생 이름·문장은 확장 프로그램의 `chrome.storage.local` 에만 저장되고 외부로 보내지 않는다.
사이드패널의 [초기화] 로 지울 수 있다.

## 확장 프로그램 쪽에서 미리 시험하기 (개발 설치)

사이드패널 개발용 칸의 **예시 데이터** 에서 이 형식을 그대로 넣어 볼 수 있다.

- [과세특 예시] / [행발 예시]: 위 형식의 예시 JSON 을 채운다 (고쳐서 써도 된다).
- [지금 나이스 표의 반/번호·조회조건으로 채우기]: 열린 나이스 표의 반/번호(번호)와 조회조건으로 예시를 만든다. 이름은 넣지 않는다.
- [이 데이터로 받기]: issamGPT 가 보낸 것과 같은 검사·저장(`background.js` 의 `acceptPayload`)을 거친다.
